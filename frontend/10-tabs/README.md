# Tabs

A simple tabs component using HTML, CSS and JavaScript

## Requirements

- [ ] Build a simple tab funtionality using HTML, CSS and JavaScript
- [ ] The page with have 4 tabs, with the first tab being active by default. When the user clicks on another tab, the content of the current tab will be hidden, and the content of the selected tab will be displayed.
