# Tooltip UI

A simple tooltip for navigation items using only HTML and CSS.

## Goals

- Help you understand how to use CSS for dynamic UI effects
- Learn how to position elements relative to each other, create smooth transitions, and make your navigation more interactive and user-friendly

## Requirements

- [ x ] Build a tooltip that appears above navigation items when hovered, using only HTML and CSS

## Bonus Points

- [ ] Create different animations for the tooltip, such as fade-in, slide-in, or scale-in effects.
