# Restricted Textarea

A textarea with live character count and a max character limit.

## Requirements

- [x] Create a textarea that tracks and displays the number of characters typed by the user, along with a maximum character limit.
- [x] As the user types, the character count will update dynamically.
- [x] Once the limit is reached, the textarea will prevent further input, and the border will turn red to visually indicate the limit has been hit.
