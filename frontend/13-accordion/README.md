# Accordian

Create an accordion component using HTML, CSS, and JavaScript.

## Goals

This project will help you practice DOM manipulation, event handling, and implementing responsive design patterns using JavaScript.

## Requirements

- [ ] Create an accordion component that displays a list of questions or headings.
- [ ] When a user clicks on a question, its corresponding answer or content section will expand while collapsing any previously opened section. This allows only one section to be open at a time, keeping the UI clean and organized.
